what null is for

null is a self control tool. it uses apple's screen time features to block apps and websites you choose, for the times you choose.

blocks are your choice

  • you decide what gets blocked, for how long, and what it takes to end a block early. some ways out are deliberately hard, and "no way out" can't be ended early except through the emergency exit.
  • don't block anything you may need in an emergency. the emergency exit ends any session at any time, and ios keeps emergency calls available regardless.
  • null relies on apple's screen time frameworks. if apple changes or limits them, or you turn off screen time access for null, blocks may stop working.

null pro

  • null pro is a one-time, non-consumable purchase through the app store. it isn't a subscription and never renews.
  • it unlocks home and lock screen widgets. everything that blocks stays free.
  • purchases are handled by apple and refunds go through apple. you can restore null pro on any device signed in to the same apple account.
