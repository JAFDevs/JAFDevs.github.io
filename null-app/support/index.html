help with null

most questions are answered below. if yours isn't, email jafdev@outlook.com and a real person will reply.

null can't block anything

null needs screen time access. open null → settings → screen time access, or iphone settings → screen time → apps with screen time access, and allow null.

a schedule didn't start

check it's switched on in the block tab, that today is one of its days, and that it has at least one app selected. overnight schedules belong to the day they start on.

i'm stuck in a session

hold "hold for emergency exit" on the session screen for three seconds. it ends any session, whatever its way out, and it's logged in your history.

my nfc chip doesn't work

pair it in settings → physical chip. any writable nfc sticker works. read-only chips can end sessions from inside null, but can't start one from the lock screen.

restoring null pro

settings → null pro → restore purchase, signed in to the apple account you bought it with.

deleting your data

settings → delete everything. it's not available while something is blocking; end it through its way out first.
